# 수집 데이터 관리

실제 촬영 데이터는 브라우저 IndexedDB와 사용자가 명시적으로 내려받은 JSON으로 관리합니다. 이 폴더에는 실제 데이터·영상·개인정보를 커밋하지 않습니다. `.gitignore`는 이 안내 파일만 허용합니다.

검증된 수어 자료, 익명 촬영자 ID, 세션 ID, 표현 고유 ID를 사용하세요. 배포·공유 전 별도 동의와 데이터 사용 범위를 관리해야 하며, 익명 ID도 개인의 동작 데이터와 연결될 수 있습니다. 학습·평가 분할은 촬영자 또는 세션 단위로 합니다. 정적 표현과 동적 표현 모두 시간 순서의 시퀀스로 저장합니다.

테스트의 합성 좌표는 단위 검사 용도이며 실제 KSL/ASL 표현 자료가 아닙니다. 데이터 구조와 전처리 규칙은 `docs/MODEL_SPEC.md`를 참고하세요.
