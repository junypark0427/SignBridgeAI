# 학습 데이터 트림·품질 검사 (v0.4.0)

일반 Try AI는 **최소 유효 프레임 1개**로 기술적 비교를 허용하며 10개 미만·짧은 동작·내부 결측은 경고로 표시하고 진행할 수 있습니다. 손 좌표 전무·형식 오류는 제외합니다. 기본 비교는 보간하지 않습니다. 아래 10프레임·독립 검증·샘플별 학습 포함 조건은 보존한 고급 TensorFlow 개발 화면 `#advanced/model`에만 적용하며 기본 사용 흐름을 막지 않습니다. 상세 비교 규격은 [COMPARISON_SPEC](COMPARISON_SPEC.md)을 참고하세요.

## 원본과 학습용 사본

IndexedDB·Supabase·일반 JSON 백업에는 원본 시퀀스를 보존합니다. 학습 불러오기 시 처음/마지막으로 손이 감지된 프레임을 찾아 바깥 구간만 제거하고 사본의 시작/종료 시각·상대 시각·길이를 다시 계산합니다. 프레임의 절대 시각과 남은 순서는 유지합니다. 원본 미검출률이 30%를 넘었다는 이유만으로 제외하지 않습니다.

사본은 `training_derivation`으로 원본 ID·트림 범위·보정 수를 명시하며 공용 업로드 함수는 이 사본을 원본으로 업로드하는 것을 거부합니다. 원본 schema_version과 좌표 전처리 버전은 변경하지 않습니다.

## 품질과 사용자 결정

- 형식 오류, 손이 한 번도 검출되지 않음, 필요한 손이 실제로 감지된 유효 프레임 10개 미만은 별도 사유로 제외합니다. 중복 ID·다중 촬영자 세션·단어 정보 충돌도 제외합니다. 보정한 프레임으로 실제 유효 프레임 최소 개수를 채우지 않습니다.
- 트림 후 미검출/필요 손 부족 비율 30% 초과, 중간 결측 250ms 초과, 좌우 판정 불확실, 트림 후 0.5초 미만은 경고입니다. 샘플별로 '경고 확인 후 포함하기'를 선택하면 학습에 포함하고, 체크 해제로 취소합니다. 선택은 현재 학습 화면에 적용하며 원본 품질 기록을 바꾸거나 성능을 보장하지 않습니다.
- 단어별 필요한 손은 자동·한 손·양손으로 지정합니다. 자동은 유효 양손 관측이 3프레임 이상이면 양손으로 판정하는 보조 규칙이며 단어의 언어적 특성을 아는 판정이 아닙니다. 양손 단어는 담당자가 명시적으로 지정하세요. 양손 설정에서는 한 손 프레임을 불완전 프레임으로 계산합니다. Unknown·중복 좌우·퇴화 좌표도 정상 유효 손으로 세지 않습니다.
- 샘플 표에 원본/트림 후 프레임 수와 미검출률, 실제 유효 프레임 수, 한 손 부족 수, 보정 수, 보정 후 잔여 결측률, 최종 포함/확인 대기/사용 불가/사용자 제외를 표시합니다. 원본 비율과 트림 후 비율은 보정 전의 실제 관측 기준입니다.

## 짧은 중간 결측 보정 (선택, 기본 꺼짐)

최대 120ms로 양끝이 둘러싸인 동일 Left/Right 손에만 시간 가중 선형 보정을 적용합니다. 양끝 신뢰도 0.6 이상, 손목 변위 0.15 이하, 모든 관절의 3차원 변위 0.25 이하인 경우만 허용합니다. Unknown·좌우 중복·손 바뀜·큰 위치 변화·긴 결측은 보정하지 않습니다. 손별 처음/끝 구간으로 외삽하지 않습니다. 임계값은 정규화 영상 좌표 기준의 보수적인 규칙이며 실제 촬영 조건별 검증이 필요합니다.

보정 좌표는 학습용 사본에만 존재합니다. 원본의 빈 hands 배열을 채우지 않습니다. 모델 메타데이터에 보정 옵션과 `hand-span-continuity-v2` 규격을 기록합니다.

## 학습·추론 일치와 이전 모델

새 모델 입력 규격은 `trim-continuity-32-duration-v2`, 텐서는 기존과 같은 32×138입니다. 학습과 추론에서 같은 트림·선택적 보정·리샘플링을 사용하고 단어별 필요한 손 수를 모델에 보존합니다. 추론은 상위 후보의 손 요구 조건도 확인하여 양손 프레임이 부족하면 확신 부족으로 처리합니다.

이전 `nearest-time-32-duration-v1` 모델도 읽을 수 있으며 해당 모델에는 기존 원본 입력·30%·0.5초 조건을 그대로 적용합니다. 입력 규격이 바뀐 모델에 이전 전처리를 몰래 적용하지 않습니다. 실제 데이터로 새 모델을 다시 학습하여 배포하는 것을 권장합니다.

각 단어 학습 2개·독립 검증 1개, 촬영자 또는 세션 분리, 단어 2종 이상 조건은 유지합니다. 사용자의 품질 경고 확인이 데이터 부족이나 학습/검증 중복 문제를 해제하지는 않습니다.
