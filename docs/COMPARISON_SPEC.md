# 즉시 동작 비교 규격 · hand-dtw-v1

기본 Try AI는 별도 신경망 학습 없이 등록된 시퀀스를 비교합니다. 단어당 1개만 있어도 실행하며 독립 검증 데이터나 여러 클래스의 존재를 요구하지 않습니다. 소량 데이터 테스트 허용과 실제 수어 인식 정확도 검증은 별개입니다.

## 준비와 입력

`src/ai/dtwRecognizer.js`의 `loadGallery`는 현재 언어의 활성 메타데이터를 UUID 커서로 끝까지 조회하고, 원본 시퀀스는 최대 3개씩 병렬로 읽어 개별 검증합니다. 테스트 행·이전 휴지통은 제외합니다. 조회 도중 행이 사라지거나 전후 ID 목록이 달라지면 불완전한 결과를 사용하지 않고 새로고침을 안내합니다. 이는 완전한 데이터베이스 스냅샷 잠금은 아니며, 관리자가 같은 ID의 내용을 동시에 변경하는 경우는 완전히 감지하지 못합니다. 각 행을 독립 검증해 손상된 행 때문에 전체 자료를 차단하지 않습니다. 같은 표현 ID의 라벨·의미·검증 메타데이터가 충돌하면 해당 자료를 제외합니다. 동일 샘플 ID는 중복 비교하지 않습니다.

`comparisonSequence`를 등록 자료와 입력 양쪽에 동일하게 사용합니다. `analyseTrainingSample`로 검증·트림하되 DTW의 최소 실제 유효 프레임은 1입니다. 손이 없거나 형식이 손상되면 제외합니다. 10프레임 미만·0.5초 미만·트림 후 내부 결측 >30%·긴 결측은 경고이며 결과 확인을 차단하지 않습니다. 원본을 바꾸지 않습니다. 기본 DTW는 좌표 보간을 하지 않습니다.

첫/마지막 **사용 가능한** 손 검출 바깥만 트림합니다. 좌우 불명·퇴화 좌표만 있는 프레임은 유효 검출이 아닙니다. 시간은 절대 시각을 유지하면서 파생 사본의 상대 시각만 재설정합니다. 두 손이 3프레임 이상 관찰되면 양손 필요로 추정하며 한 손만 있는 내부 프레임은 부분 결측으로 계산합니다. 자동 추정만으로 실제 수어의 요구 손 수를 확정할 수 없습니다.

공통 `preprocessing.js`의 137차원 벡터를 유지합니다. 손마다 presence, 절대 손목 xy, 손 크기, 손목 기준/크기 정규화 21×xyz를 두고, 양손 상대 손목 xy·presence를 덧붙입니다. 손가락 순서·방향을 회전 정렬하거나 좌우를 합치지 않습니다. 영상 비율을 보정합니다. 누락/모호한 손은 마스크로 나타내며 원본에 가짜 좌표를 쓰지 않습니다.

최대 64개 동일 시간 격자에서 가장 가까운 실제 프레임을 선택합니다. 프레임 수가 적으면 모두 사용합니다. 끝점을 포함하고 시간 순서를 보존합니다. 원본은 리샘플링하지 않습니다. 짧고 빠른 세부 움직임이 줄어들 수 있으므로 정밀 성능은 별도 검증해야 합니다.

## 거리와 후보

프레임 거리에서 손별 정규화 모양 xyz RMS×0.65, 절대 손목 xy 거리×0.25, 크기 차이×0.1을 더합니다. 한쪽 시퀀스에만 해당 손이 있으면 1의 누락 비용을 사용하며 두 쪽 모두 없으면 그 손은 제외합니다. 양쪽 프레임에 두 손이 모두 있으면 상대 손목 거리×0.2를 더하고 전체를 2로 나눕니다. 이 가중치는 초기 공학적 설정이며 수어학적 최적값이나 실측 정확도 보정값이 아닙니다.

DTW는 대각·가로·세로로만 전진하는 단조 경로를 사용합니다. 창 너비는 최대 길이의 35%와 길이 차이 중 큰 값입니다. 누적 거리를 경로 길이로 나눕니다. 서로 다른 길이와 속도에 대응하며 동작을 역순으로 바꿔 비교하지 않습니다. 시간당 이동 속도 자체는 별도 특징이 아니므로 속도만으로 구분되는 단어에는 한계가 있습니다.

단어별 가까운 샘플 최대 3개의 거리로 `0.7 × 최솟값 + 0.3 × 가까운 샘플 평균`을 계산합니다. 모든 샘플을 비교하고 표본 수가 많은 클래스가 투표 수로만 이기지 않게 합니다. 상위 5개 후보를 반환합니다. 점수는 `exp(-3 × 거리)`이며 UI에서 100점 척도로 표시합니다. 확률·정확도·검증된 신뢰도가 아닙니다.

기본 거리 허용값은 0.35입니다. 최상위 거리가 이 값을 넘거나 1·2위 거리 차이가 0.025 미만이면 불확실 안내를 표시합니다. 후보 결과는 계속 보여 줍니다. 거리 허용값은 UI에서 0.05~2로 조정할 수 있습니다. 한 클래스뿐이면 상대 분류가 불가능하다는 별도 안내를 표시합니다. 샘플 수 부족은 실행 조건으로 검사하지 않습니다.

비교 중 4개 샘플마다 이벤트 루프에 제어를 돌려주며 화면 이동 시 취소 신호로 중단합니다. 최대 프레임 제한으로 샘플당 DTW 연산량을 제한합니다. 대규모 데이터셋은 향후 Worker·대표 샘플 인덱스 등의 최적화가 필요합니다. 지금은 전체 갤러리를 메모리에 준비합니다.

## 갱신과 결과

진입·언어 변경·수동 갱신·탭 복귀·재연결·업로드 완료, 인식 시작·종료 경계에서 공용 자료를 다시 조회합니다. 매 프레임 통신은 하지 않습니다. 이전 요청은 세대 번호와 취소 신호로 무효화하여 다른 언어/화면에 늦은 응답이 적용되지 않게 합니다. DB 스냅샷 잠금은 없으므로 조회 도중 동시 변경은 다음 조회에 반영됩니다.

결과는 후보 라벨·수어 종류·점수·상위 후보·샘플 수·의미 코드·불확실 안내입니다. 대응 표현은 양 언어 메타데이터의 검증 표시·출처와 동일 의미 코드를 확인한 경우에만 표시합니다. 실제 의미나 영상이 없는 경우 만들어내지 않습니다. 얼굴·입·상체는 입력에 포함하지 않습니다.

참고: [DTW 공식 tslearn 가이드](https://tslearn.readthedocs.io/en/stable/user_guide/dtw.html). Python 라이브러리를 설치하거나 서버에서 사용하지 않으며 구현은 브라우저 JavaScript입니다.
