# 한국어 구절 생성 실험

인식 엔진과 독립된 `src/sentence/lexicon.js` 및 `koreanPhrase.js`를 사용합니다. 사전의 `label`과 `concept_id`가 모두 정확히 일치하는 KSL 단어만 해석합니다. 이는 현재 Supabase에 등록된 `사랑`/`사랑`, `배우다`/`배우다`를 식별하기 위한 명시적 매핑입니다. 다른 개념 ID는 사람이 의미를 확인한 후 사전에 별도 매핑을 추가해야 하며 단순히 이름이 비슷하다는 이유로 같은 의미라고 간주하지 않습니다.

서술어는 각 의미에 대해 자릿수, 문장 성분, 의미 역할, 허용 범주, 조사, 주어 생략 여부와 입력 순서 패턴을 정의합니다. 명사에는 사람·동물·장소·사물·음식·추상·학습 대상·직업 범주를 지정합니다. 하나의 단어가 여러 범주에 속할 수 있습니다. 이 범주는 실험을 위한 제한적 수작업 분류이며 사전 전체나 수어 의미의 보편적 분류가 아닙니다.

현재 단항 자다·걷다·웃다·울다, 이항 배우다·읽다·먹다·마시다·좋아하다·만나다·가다·살다·되다, 삼항 주다를 등록했습니다. 주다에는 수혜자/목적어 순서 두 가지를 두고, 가다의 목적지·살다의 거주지·주다의 수혜자는 필수적 부사어, 되다의 결과는 보어로 처리합니다. 분석 관점에 따른 자릿수·필수 부사어의 견해 차이가 있으므로 이 규격은 각 서술어의 **등록된 특정 의미와 패턴**에 한정합니다. 자세한 언어학적 검토에는 [국립국어원 서술어·문장 성분 자료](https://www.korean.go.kr/nkview/nklife/2005_4/2005_0411.pdf)와 [주다의 문형 설명](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=98&pageIndex=1&qna_seq=328276)을 참고합니다.

마지막 단어가 등록된 서술어인지, 앞선 각 단어가 명사인지 확인한 뒤 패턴별 성분 개수와 의미 범주를 검사합니다. 주어만 생략할 수 있고 다른 필수 성분은 채워야 합니다. 둘 이상의 패턴에 서로 다른 역할 배치가 가능하면 모호한 입력으로 보류합니다. 등록된 배열 순서는 실험용 가정으로, 한국수어 문법을 일반적으로 판정하지 않습니다. 불확실한 인식 결과를 사용자가 추가하면 그 사실은 목록에 표시되며 자동 수정하지 않습니다.

받침 유무로 이/가·을/를을 고르고 나/저/너의 주격 형태를 별도 처리합니다. 장소에는 에/에서, 수혜자에는 에게를 사용합니다. 기본형은 사전형을 그대로 출력하며 현재형은 등록된 규칙 동사의 어간 받침과 ㄹ 받침 규칙으로 평서형을 생성합니다. 시제·높임·불규칙 활용·다의어·복합 명사·문맥 복원은 지원하지 않습니다. 누락된 인물은 만들어내지 않습니다.

단위 테스트는 합성 단어 배열에 대한 검증입니다. 실제 수어 인식률이나 KSL 문법적 정확성에 대한 평가가 아닙니다. 새로운 단어/패턴을 추가할 때는 검증된 출처, 특정 의미, 가능한 역할, 순서, 중의성, 잘못된 입력에 대한 테스트를 함께 검토하세요.
