# SignBridge AI

한국수어(KSL)·미국수어(ASL)의 **개별 단어 동작을 시간 순서가 있는 시퀀스로 수집**하는 브라우저 앱입니다. 원본 웹캠 영상 대신 MediaPipe가 추출한 최대 두 손의 21개 관절과 시간 정보를 저장합니다.

현재 구현 범위는 데이터 수집·품질 검토·공통 전처리입니다. 수어 단어를 분류하는 학습 모델, 교차 수어 변환, 문장 인식·생성·번역, 음성·마이크, 서버·데이터베이스 서버는 구현하지 않습니다. Hand Landmarker의 손 검출 모델은 수어 단어 인식 모델과 다릅니다.

초기 단어 인식 모델의 범위는 **손동작 정보만으로 구별 가능한, 사전에 선정된 제한된 KSL·ASL 단어**입니다. 수집 항목은 손가락 모양, 손 방향, 시간에 따른 움직임, 손의 절대 이미지 위치, 양손의 상대 위치입니다. 얼굴 표정·입 모양·머리·상체 움직임은 현재 수집·인식 대상에서 제외합니다. 화면에 상체가 보이더라도 얼굴·자세 관절은 추출하지 않습니다. 후속 Face Landmarker·Pose Landmarker는 별도 추적 모듈과 버전이 명시된 데이터 채널로 추가할 수 있습니다.

## 실행

- Node.js LTS 22.12 이상 (개발 검증 환경: Node 24.22.1)
- npm 및 카메라를 지원하는 최신 Chrome/Edge 권장
- 카메라는 `localhost` 또는 HTTPS에서만 사용 가능

```sh
npm ci
npm run dev
```

브라우저에서 터미널에 표시된 주소(기본 `http://127.0.0.1:5173/`)를 엽니다. 처음 설치할 때 공식 MediaPipe 모델을 내려받고 패키지의 WASM을 `public/wasm/`에 복사합니다. 설치 및 초기 준비에는 인터넷이 필요하며 이후 앱은 같은 출처의 정적 파일만 사용합니다. 카메라 영상·수집 데이터는 외부로 전송하지 않습니다.

```sh
npm test                 # 핵심 로직·IndexedDB·카메라 제어 자동화 테스트
npm run build            # dist/ 생성
npm run preview          # 프로덕션 결과 확인
npm run assets:prepare   # WASM 복사 및 모델 SHA-256 재검증
```

이 작업 환경에 기본 npm 명령이 없다면 작업 폴더에 준비된 도구로 `node .tools/package/bin/npm-cli.js run dev`를 실행할 수 있습니다. `.tools/`는 로컬 도구이며 Git에 포함되지 않습니다. 다른 개발자는 표준 Node.js LTS와 npm을 설치해 위 명령을 사용하세요.

## 수집 방법

1. **KSL 또는 ASL**을 선택하고 **단어 등록**을 누릅니다. 단어 이름, `concept_id`, 고유한 `sign_id`를 입력합니다. 표현 변이마다 별도 ID를 부여하세요. 검증된 수어 사전·영상 등의 출처와 설명을 기록할 수 있습니다. 실제 수어 단어 목록은 임의로 제공하지 않습니다.
2. 같은 의미의 KSL/ASL 항목에 공통 의미 코드를 지정할 수 있습니다. 코드 공유만으로 완전한 대응이라고 간주하지 않습니다. 담당자가 출처를 확인한 경우에만 ‘대응 관계 검증’에 표시하세요. 검증 표시에는 출처가 필요합니다.
3. 익명 촬영자 ID와 세션 ID를 확인합니다. 실제 이름·연락처를 입력하지 마세요. 촬영자나 촬영 환경이 바뀌면 **새 세션**을 만드세요. 한 세션에 서로 다른 촬영자를 등록할 수 없습니다.
4. **카메라 시작**을 누르고 권한을 허용합니다. 장치 변경은 카메라를 종료한 후 선택합니다. 상체와 양손을 프레임 안에 두세요. 미리보기만 거울 모드이며 좌표 입력은 반전하지 않습니다.
5. **녹화 시작** → 기본 3초 카운트다운 → 단어를 한 번 표현 → **녹화 종료 및 검토**. 자동 종료는 선택 사항이며 초기 3초, 설정 범위 1~120초입니다. 수동 촬영도 브라우저 메모리 보호를 위해 최대 120초로 제한합니다. 한 녹화에 서로 다른 단어를 연속으로 담지 마세요.
6. 관절 좌표 재생·프레임 탐색으로 움직임과 미감지 프레임을 확인하고 **이 시퀀스 저장** 또는 **저장하지 않기**를 선택합니다. 미감지 프레임도 `hands: []`로 남습니다. 감지 실패 비율이 30%를 넘으면 경고하며, 경고가 있어도 담당자가 검토 후 저장할 수 있습니다.
7. 하단에서 단어별/촬영자별 수량, 길이, 평균 프레임, 미감지·양손 프레임, 유효성을 확인합니다. 목록의 **검토**에서 저장된 시퀀스를 재생하고, **삭제** 또는 **마지막 수집 삭제**로 잘못된 샘플을 제거할 수 있습니다. 시퀀스가 없는 단어는 **빈 단어 등록 삭제**로 제거 후 다시 등록할 수 있습니다.

카메라 종료·장치 연결 해제·탭 숨김은 진행 중인 녹화와 카운트다운을 취소합니다. 이미 검토 대기 중인 시퀀스는 저장/폐기를 선택할 수 있습니다. 탭을 닫기 전 미저장 작업이 있으면 브라우저 확인 창을 요청합니다. 운영체제가 강제로 프로세스를 종료하면 저장 전 데이터는 복구되지 않습니다.

## JSON과 로컬 저장

- 저장 버튼을 누른 샘플과 등록 단어는 IndexedDB에 보관하며 새로고침 후 복원됩니다. 데이터는 사이트 출처(호스트·포트)와 브라우저 프로필에 종속됩니다. 같은 주소를 계속 사용하세요.
- 브라우저 데이터 삭제·저장 공간 회수·비공개 모드 종료로 유실될 수 있습니다. 정기적으로 **JSON 다운로드**를 눌러 별도 백업하세요. 자동으로 JSON 파일을 만들거나 다운로드하지 않습니다.
- 내보내기는 **현재 언어 / 전체 언어**를 선택합니다. 원본 좌표 데이터만 내보내며 특징 벡터는 공통 모듈에서 필요할 때 계산합니다.
- **JSON 불러오기**는 최대 100MB 파일을 검사한 뒤 기존 데이터에 원자적으로 병합합니다. 같은 ID·같은 내용은 건너뛰고, 같은 ID·다른 내용이나 지원하지 않는 버전·잘못된 참조는 전체 가져오기를 거절합니다. 기존 내용을 덮어쓰지 않습니다.
- 저장 공간 부족·IndexedDB 실패 시 오류를 표시합니다. 저장에 실패한 검토 대기 샘플은 남아 있으므로 공간을 확보하고 재시도하세요.
- 전체 데이터셋을 메모리에 읽어 검증하므로 대규모 수집은 언어별/프로젝트별 JSON으로 백업·분리하세요. IndexedDB는 서버 백업이 아닙니다.

## 파일 구조

```text
src/
  main.js                        # 앱 상태·이벤트·녹화 흐름
  camera/cameraManager.js         # 비디오 전용 카메라 수명 주기
  mediapipe/handTracker.js        # VIDEO, 최대 두 손, GPU → CPU 대체
  collector/wordCollector.js     # 시간 순서 기반 시퀀스 수집
  collector/datasetManager.js    # IndexedDB·검증·중복/충돌 병합
  shared/dataSchema.js           # 버전·유효성·품질 지표
  shared/preprocessing.js        # 공통 특징 및 그룹 분할
  ui/collectorUI.js              # UI·원본 좌표 재생·관절 그리기
  ui/base.css
  style.css
public/models/                   # 공식 모델·출처·해시
public/wasm/                     # 설치 시 생성 (Git 제외)
scripts/prepare-assets.mjs
tests/                           # 합성 좌표 테스트, 실제 수어 데이터 아님
data/README.md
docs/MODEL_SPEC.md
docs/VALIDATION.md
```

## GitHub 협업

저장소: https://github.com/junypark0427/SignBridgeAI

- `main`: 통합·안정 버전. 직접 푸시하거나 강제 병합하지 않습니다.
- `feature/data-collector`: 이번 데이터 수집기.
- `feature/ksl`, `feature/asl`: 향후 언어별 모델 개발.
- 공통 스키마·전처리는 `src/shared/`를 재사용하고 변경 시 양쪽 담당자와 버전을 맞춥니다. 초기 저장소는 비어 있었으므로 이번 브랜치가 첫 구현입니다. 원격에 기존 `main` 커밋이 없었으며 새 main 브랜치를 임의로 만들지 않습니다.
- 실제 촬영 데이터, 다운로드한 데이터셋, 개인정보, 인증 파일, `.env`, 도구 캐시는 커밋하지 않습니다. `data/`에는 안내 문서만 추적합니다.

## 다음 단계

수어 전문가가 검증한 단어·의미 코드·표현 변이·자료 출처를 먼저 확정하고 다양한 촬영자·환경에서 수집합니다. 촬영자 단위로 학습/검증/테스트를 분리한 뒤 각 담당자가 동일한 전처리 버전으로 KSL·ASL 시퀀스 모델을 학습하세요. 미등록 표현 거절 임계값, 신뢰도 보정, 시간적 안정화를 별도로 평가합니다.

손 관절만으로 모든 수어 단어를 구분할 수는 없습니다. 얼굴·머리·상체 등 비수지 신호가 필요한 표현은 현재 데이터 범위의 한계입니다. 문장 수준 확장은 구간 분리와 문법·맥락 해석을 별도 모듈로 연구합니다. 단어 인식 결과를 이어 붙이는 방식으로 문장 번역 완료를 주장하지 않습니다.

데이터 계약은 [MODEL_SPEC](docs/MODEL_SPEC.md), 실행한 검사와 미검증 항목은 [VALIDATION](docs/VALIDATION.md)을 참고하세요.

공식 API 기준: [MediaPipe Hand Landmarker Web](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js), [Vite 시작하기](https://vite.dev/guide/). 의존성 버전은 `package.json`과 `package-lock.json`으로 고정합니다.
