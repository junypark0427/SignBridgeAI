# SignBridge AI

한국수어(KSL)·미국수어(ASL)의 **단어 동작을 등록하고 바로 비교하는** 웹앱입니다. 메인 메뉴는 ‘학습시키기’와 ‘Try AI’입니다. 손동작으로 구별 가능한 선정 어휘가 대상이며 얼굴·입·머리·상체·문장 번역은 현재 범위에서 제외합니다.

공개 사이트: [signbridgeai1.netlify.app](https://signbridgeai1.netlify.app/). 기존 GitHub·Netlify·Supabase를 유지합니다.

## 학습시키기

1. KSL/ASL을 고르고 단어를 등록합니다. 검증된 사전·영상에 따라 이름, 공통 의미 코드 `concept_id`, 고유 `sign_id`, 설명·출처를 입력합니다. 같은 의미 코드만으로 완전한 수어 대응이라고 간주하지 않습니다.
2. 익명 촬영자·세션 ID를 확인합니다. 실명·연락처를 입력하지 않고 촬영자·환경이 달라지면 새 세션을 만듭니다.
3. 카메라 시작 → 녹화 시작 → 기본 3초 카운트다운 → 단어 한 번 → 녹화 종료 및 검토. 자동 종료는 선택이며 수동 녹화는 최대 120초·7200프레임입니다.
4. 좌표 재생·트림 전후 품질을 확인하고 저장합니다. 품질 경고만으로 저장을 막지 않습니다. 원본 영상은 저장하지 않습니다.
5. IndexedDB 저장 후 Supabase에 전체 시퀀스를 한 행으로 업로드합니다. **업로드 확인됨**이 표시되어야 팀에 공유된 상태입니다. 실패하면 로컬에 남고 재연결·수동 재시도로 복구합니다.
6. **팀 공용 데이터**에서 전체·KSL·ASL·단어별 수량, 검토, 삭제, JSON 백업을 사용합니다. 동기화 세부 상태·촬영자/세션 필터·이전 휴지통은 접힌 상세 메뉴에 있습니다. 로컬 사본·JSON 복구도 별도 접힌 영역에 있습니다.

최대 두 손의 21개 좌표, 좌우, 방향, 움직임, 절대 위치와 양손 상대 위치를 유지합니다. 미검출 프레임은 `hands:[]`로 저장하며 좌표를 만들지 않습니다. 화면 이동·탭 숨김 때 카메라를 종료합니다.

## Try AI

Try AI의 **문장 인식 (Beta)**는 KSL 단어를 하나씩 인식해 확인한 뒤 누적하는 제한적 한국어 구절 실험입니다. 카메라를 켜고 ‘인식 시작 → 단어 한 번 → 인식 종료 → 문장에 추가’를 반복하세요. 인식이 불확실하면 표시하며 사용자가 직접 확인해 추가합니다. 누적 단어는 등록 목록으로 수정하거나 순서를 바꾸고 삭제할 수 있습니다. ‘사랑 → 배우다’를 추가한 뒤 ‘문장 변환’을 누르면 기본형 **사랑을 배우다**가 표시됩니다. 현재형을 선택하면 **사랑을 배운다**입니다.

초기 사전에는 14개 서술어와 29개 명사·대명사가 있습니다. 서술어마다 자릿수·주어·목적어·보어·필수적 부사어의 의미 범주와 허용 순서를 명시합니다. 명사 범주와 등록 순서가 맞는 경우에만 조사를 결합하며 주어는 생략할 수 있습니다. 사전에 등록되지 않은 개념이나 필수 성분이 부족하고 역할이 모호한 경우에는 원본 단어를 유지하고 변환을 보류합니다. 단어의 label과 concept_id가 사전의 의미와 모두 일치해야 합니다. 예를 들어 `친구 + 책 + 주다`는 ‘친구에게 책을 주다’로 처리하며 생략된 주어를 만들어내지 않습니다. 조사·기본형/현재형은 소수의 명시된 규칙을 사용합니다. 연속 동작 자동 분리, 얼굴·공간 문법, ASL 문장과 완전한 수어 번역은 지원하지 않습니다. [문법 사전과 제약](docs/SENTENCE_RULES.md)을 참고하세요.

1. Try AI → KSL/ASL 선택. 최신 공용 데이터를 자동 조회합니다.
2. 샘플 수와 품질 안내를 확인합니다. 별도의 모델 학습·다운로드·파일 배치는 필요하지 않습니다.
3. 카메라 시작 → 인식 시작 → 단어 하나 수행 → 인식 종료(최대 10초).
4. 가장 유사한 후보, 비교 점수, 상위 후보, 샘플 수, 의미 코드·검증된 대응 자료를 확인합니다. 체험 영상·좌표는 저장·업로드하지 않습니다.

단어 한 종류에 샘플 1개여도, 두 단어에 각 1개여도 비교합니다. 3~5개·10개 이상도 모두 활용합니다. 데이터 부족은 안내이며 실행 차단 조건이 아닙니다. 0개면 등록 화면을 안내합니다. 형식 손상·사용 가능한 손 좌표 전무는 제외합니다. 극히 짧은 자료도 비교는 허용하지만 움직임 평가가 제한적이라고 경고합니다.

기본 알고리즘은 **DTW 시퀀스 유사도 + 최근접 이웃**입니다. 등록 샘플과 입력에 같은 자동 트림·137차원 공통 전처리를 적용합니다. 손 모양·방향·절대 위치·양손 상대 위치·좌우·시간 순서를 보존하며 최대 64개 시간 기반 프레임과 단조 시간 정렬로 길이·속도 차이에 대응합니다. 누락 손은 마스크·차이 비용으로 처리합니다. [비교 규격](docs/COMPARISON_SPEC.md)을 참고하세요.

점수는 `100 × exp(-3 × DTW 거리)`이며 **정확도나 통계적 확률이 아닙니다**. 후보가 하나면 그 단어와 닮은 정도만 의미합니다. 차이가 크거나 후보가 비슷하면 불확실 안내를 표시하되 결과 확인은 허용합니다. ‘비교 기준 안내 및 조정’에서 기준을 바꿀 수 있습니다. 실측 정확도로 보정한 값은 아닙니다.

Try AI 진입·언어 변경·새로고침·탭 복귀·재연결·동기화 완료 시 최신 자료를 조회합니다. 데이터 준비와 카메라 연결이 끝나면 인식 시작 시 바로 녹화하고, 종료 후 비교 직전에 최신 자료를 다시 확인하여 원격 추가·삭제를 반영합니다. 인식은 10초가 지나면 자동 종료되며 종료 버튼은 녹화 중에만 활성화됩니다. 매 프레임 DB 요청은 하지 않습니다. 통신 실패를 최신 자료 준비 완료로 표시하지 않습니다.

한국어/영어 의미는 등록 라벨과 검증된 대응 표현에서 표시합니다. 출처와 대응 검증 표시가 양쪽에 있는 동일 의미 코드의 자료만 대응 수어로 제공합니다. 자료가 없으면 미등록으로 표시하며 번역·수어 영상을 임의 생성하지 않습니다.

## 자동 트림과 품질

원본 시퀀스·JSON·DB는 보존하고 비교/학습용 사본에서 첫 유효 손 검출 전과 마지막 검출 후만 트림합니다. 내부 누락은 남기고 미검출률·실제 유효 프레임·양손 부족을 다시 계산합니다. 두 손이 여러 프레임에서 검출되면 양손 필요로 추정합니다. 언어적 손 수를 확정하는 것은 아니므로 수집자가 검토해야 합니다.

전체 미검출률 >30%만으로 자동 제외하지 않습니다. 내부 누락·짧은 구간·양손 부족은 경고와 재촬영 권장 사항입니다. Try AI에서는 안내를 확인한 뒤 진행할 수 있고 잘못된 자료는 삭제할 수 있습니다. 긴 결측은 복원하지 않습니다. 고급 TensorFlow 학습에는 최대 120ms의 연속적인 짧은 결측만 선택적으로 보정하는 기능을 보존했습니다(기본 꺼짐). [품질 규격](docs/TRAINING_QUALITY.md)을 참고하세요.

## 공용 데이터 삭제와 공개 권한

공용 행 또는 검토창의 **삭제** → 언어·단어·촬영 시각·ID 확인 → **영구 삭제**. 취소하면 삭제하지 않습니다. Supabase `sign_samples`의 실제 행·좌표를 UUID 기준으로 삭제하고 SELECT 부재·삭제 기록을 확인한 뒤 목록과 개수를 갱신합니다. 필요한 경우 먼저 **조회 조건 전체 JSON**으로 백업하세요.

2026-10-31 사용자 승인에 따라 anon SELECT·INSERT·DELETE를 허용합니다. **사이트 방문자 누구나 팀 자료를 영구 삭제할 수 있습니다.** 회원가입·관리자·서버는 추가하지 않습니다. 원본 좌표 UPDATE는 차단하고 이전 휴지통 `archived` 열만 수정할 수 있습니다. 실제 영상·실명·민감 정보를 저장하지 마세요. 촬영 동의·공개 공유 범위는 팀이 관리합니다. 사용자별 과다 추가·데이터 오염 방지는 구현하지 않았습니다.

삭제 시 `sign_sample_deletions`에 UUID·삭제 시각만 남깁니다. DB 트리거가 같은 UUID INSERT를 거절하여 다른 기기의 오래된 IndexedDB·백업·이전 앱에서 자동 재등록되는 일을 막습니다. 그 UUID는 재사용할 수 없습니다. 좌표·라벨·촬영자 정보는 삭제 기록에 남기지 않습니다. 다른 기기에 이미 내려받은 사본·백업까지 원격으로 지울 수는 없습니다. 로컬 삭제는 브라우저 사본만 지웁니다. 이전 휴지통은 상세 메뉴에서 복원할 수 있고 신규 삭제는 실제 DELETE입니다.

## JSON 백업과 공유 점검

전체 JSON은 페이지를 끝까지 조회하고 전후 수가 바뀌면 다시 시도합니다. 로컬 JSON 입출력도 유지합니다. 같은 ID·내용은 건너뛰고 충돌은 덮어쓰지 않습니다. 삭제된 UUID는 백업에서 불러와도 다시 업로드하지 않습니다. 비 UUID 자료는 로컬 보존하고 전송만 거절합니다.

다른 기기에 자료가 안 보이면 같은 공개 사이트·버전을 확인하고, 원본 기기의 ‘업로드 확인됨’ 확인 후 공용 목록을 새로고침하세요. 단어 등록만으로는 공유되지 않습니다. 로컬 목록·선택 단어는 브라우저마다 다릅니다. 필요하면 공용 페이지를 로컬로 가져오세요. 상세 필터 초기화로 전체 언어를 확인합니다. 실패하면 원본 JSON을 먼저 백업하고 재시도합니다. 확인 전에 DB·브라우저 자료를 초기화하지 마세요.

## 실행·Netlify

Node.js LTS 22.12 이상(검증 환경 24), npm, 최신 Chrome/Edge를 사용합니다. 웹캠은 localhost/HTTPS가 필요하며 index.html 직접 열기는 지원하지 않습니다.

```sh
npm ci
# .env.example → .env.local에 기존 Supabase URL/Publishable Key 입력
npm run dev
npm test
npm run build
npm run preview
```

기본 주소 `http://127.0.0.1:5173/`. npm이 경로에 없는 이 환경은 `node .tools/package/bin/npm-cli.js`를 사용할 수 있습니다. 설치 시 MediaPipe 공식 모델 해시를 검사하고 WASM을 복사합니다. TensorFlow.js는 고급 모델 사용 시 지연 로드합니다.

기존 Netlify `signbridgeai1`: build `npm run build`, publish `dist`, Node 24, production branch `feature/data-collector`. `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`를 Project configuration → Environment variables에서 Build 용도로 설정하고 재배포합니다. 기존 두 변수를 유지하며 실제 값/.env.local은 Git 제외입니다. 변수 변경 후에는 새 빌드가 필요합니다. Vite 공개 키는 번들에 포함되고 Secret/service_role은 거절합니다. 소스 index.html 하나를 배포하지 마세요.

[DB 설정·SQL 적용 순서](docs/DATABASE_SETUP.md), [데이터 규격](docs/MODEL_SPEC.md), [검증 결과](docs/VALIDATION.md)를 참고하세요. Python/추론 서버·Netlify Functions·로그인 시스템은 없습니다.

## 보존한 고급 학습·디자인·협업

TensorFlow.js의 실제 Conv1D 학습·독립 촬영자/세션 검증·저장·다운로드 코드는 유지했습니다. 일반 메뉴에 노출하지 않으며 개발용 `#advanced/model`로 접근합니다. 고급 학습의 최소 클래스/학습·검증 조건은 **기본 DTW Try AI에 적용하지 않습니다**. 검증된 공개 신경망 모델은 아직 없으며 registry KSL/ASL은 null입니다. [모델 배포 안내](docs/MODEL_DEPLOYMENT.md)는 고급 기능에 해당합니다.

`design` 브랜치는 수정·병합하지 않았습니다. 팀원의 부드러운 카드, 카메라/결과 구분, 큰 시작·종료 버튼을 참고하고 현재 색상을 유지합니다. 기능은 `ai`, `database`, `camera`, `mediapipe`, 공통 규격은 `shared`, 화면은 `ui`, 시각 스타일은 `polish.css`로 분리하여 향후 디자인 교체가 가능합니다. 팀원 폴더를 보존합니다.

main 직접 Push·강제 Push를 하지 않으며 현재 `feature/data-collector`를 사용합니다. 실제 학습 자료·환경 변수·합성 QA 모델은 Git 제외입니다. 다음 단계는 검증된 어휘 수집, 미참여 촬영자 평가, DTW 가중치·불확실 기준 보정입니다. 문장 수준 기능은 구간 분리·문법·맥락 연구 과제로 남깁니다.
